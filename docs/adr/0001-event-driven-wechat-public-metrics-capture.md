# ADR 0001：微信文章互动数据采用身份校验的事件驱动抓取

- 状态：Accepted
- 日期：2026-08-26
- 范围：非当前登录公众号的文章互动数据抓取

## 背景

微信文章页的阅读、点赞、推荐、分享、留言和收藏数据，需要由已登录的微信客户端完成授权访问。仅按标题搜索并点击第一条结果存在误命中风险；固定等待若干秒后再扫描缓存，也会漏掉短暂生成后被替换的 Chromium 缓存文件。

长期目标是复用微信会话直接请求文章接口，但在接口、令牌刷新和风控边界尚未完成验证前，产品首先需要一条稳定、可回收的前台自动化路径。

## 决策

一次用户操作被建模为一个单次抓取事务：

1. 先尝试已存在的近期匹配缓存。
2. 缓存未命中时，只发起一次微信全局搜索，不自动重开搜索窗口。
3. 标题只用于召回。结果候选按完整标题、公众号、发布时间和结果语义角色排序，不再盲点第一条坐标。
4. 点击前启动缓存监听。文件事件发生时立即快照候选文章页字节，避免操作函数返回前临时文件已消失。
5. 数据写入前再次校验文章身份：
   - 有 canonical ID 时校验 `__biz + mid + idx`，并在响应包含 `sn` 时校验 `sn`；
   - 缺少 canonical ID 时校验 `__biz + 完整标题 + 发布日期`。
6. 以匹配缓存中的互动数据为导航成功条件。成功即返回并回收本事务创建的独立微信网页窗口，再恢复原应用焦点；若搜索复用了用户已有窗口，则不冒险关闭共享窗口。
7. 超时只作为失败边界，不作为正常同步手段。

## 非功能要求

- 正确性：不允许把相似标题或其他公众号文章的数据写入目标文章。
- 有界副作用：一次点击最多触发一次全局搜索，最多拥有一个可识别的新网页窗口。
- 响应性：缓存事件到达后立即解析；不额外固定等待两秒。
- 可恢复性：成功或失败都恢复调用前应用焦点；只关闭能够证明由本事务创建的窗口。
- 隐私：日志仅记录字符数、匹配布尔值、耗时和窗口 ID，不记录文章会话令牌、Cookie 或完整授权 URL。
- 可测试性：缓存字节解析、复合身份证据、发布时间冲突和 canonical ID 冲突必须有单元测试。

## 取舍与替代方案

- 仅延长固定等待：拒绝。不能解决临时缓存消失和错误结果点击。
- 仅按标题点击第一条：拒绝。标题不是唯一身份。
- OCR：拒绝。速度、稳定性和可验证性均低于辅助功能树与响应身份校验。
- 最小化窗口或移动到其他 Space：暂不采用。微信全局搜索仍依赖前台键盘/窗口语义，后台投递在不同版本上不可靠。
- 直接复刻微信接口：保留为第二阶段。当前实现会保留 canonical 身份边界，使未来可将“微信 UI 导航器”替换为“本机会话请求器”，而不改变解析、校验、存储和前端更新契约。

## 失败模式

- 搜索页未暴露可匹配的辅助功能节点：本次失败并关闭可确认属于本事务的窗口，不使用盲点坐标。
- 用户锁屏或辅助功能权限缺失：在操作前失败，不创建搜索页。
- 页面已删除、不可见或未返回互动字段：不写入伪造的零值。
- 微信复用已有网页窗口：保留页面，避免误关用户内容；后续可在验证稳定的标签页身份接口后补充标签级回收。
